# GHATVERSE Frontend

Premium React + Vite frontend for the GHATVERSE Western Ghats travel platform.

## Included
- Cinematic responsive homepage
- Destination discovery
- Six-state Western Ghats explorer
- Curated travel packages
- Stays
- Reels / visual discovery
- Interactive trip planner
- Responsive mobile navigation
- Reusable data-driven React components
- Flask-ready frontend structure

## Run locally

```bash
npm install
npm run dev
```

Then open the Vite local URL shown in the terminal.

## Build

```bash
npm run build
```

## Next integration
Replace the local arrays in `src/App.jsx` with calls to the GHATVERSE Flask API. Keep PostgreSQL IDs as canonical place/hotel identifiers and use CDN URLs for media.
